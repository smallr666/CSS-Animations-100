How to use

把動畫庫帶進任何網站，只要兩個檔案。

  1. 把 motion-lib.css、motion-helpers.js 放進網站的 assets/。
  2. 在元素加上 class，例如 class="mo-fade-up"。
  3. 捲到畫面才播放：再加 mo-onview。
  4. 客製：style="--mo-color:#2E9E6B; --mo-dur:1.2s"。
  5. 深色模式：在 <html> 加 data-theme="dark"。
  6. 系統開啟「減少動態」時，動畫會自動關閉（無障礙）。
<head>
  <link rel="stylesheet" href="assets/motion-lib.css">
</head>
<body>
  <h2 class="mo-fade-up mo-onview">颱風應變流程</h2>

  <div class="mo-mascot mo-mascot--wave" data-face="wink">
    <!-- 抵家 SVG -->
  </div>

  <script src="assets/motion-helpers.js"></script>
</body>
